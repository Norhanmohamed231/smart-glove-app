# استكشاف الأخطاء

دليل سريع للمشاكل الشائعة وحلولها.

## Bluetooth والاتصال

### لا يظهر SignGlove في المسح

| السبب المحتمل | الحل |
|---------------|------|
| لم يُجرَ Pair من النظام | Settings → Bluetooth → Pair مع SignGlove |
| صلاحيات مرفوضة | إعدادات التطبيق → Bluetooth + Location |
| Bluetooth مغلق | فعّله من شريط الإعدادات |
| القفاز مطفأ | شغّله وانتظر READY |

### فشل الاتصال (Connection Failed)

- تأكد من Pairing أولاً
- أغلق التطبيقات الأخرى المتصلة بالقفاز
- أعد تشغيل Bluetooth على الهاتف
- أعد تشغيل القفاز

### «Enable Bluetooth» رغم أن BT مفعّل

صلاحيات runtime غير ممنوحة — أعد تثبيت التطبيق بعد منح **Nearby devices** و **Location**.

## البيانات والـ Parser

### متصل لكن flex = 0 دائماً

| السبب | الحل |
|-------|------|
| حساسات غير موصولة | راجع توصيلات الـ firmware |
| معايرة لم تكتمل | انتظر شاشة READY على OLED |
| تنسيق خاطئ | تأكد من سطور `DATA,...` بـ 14 حقل |

### البيانات تصل لكن لا شيء يعمل (كان: buffer يكبر)

**السبب:** نهاية السطر `\r` بدون `\n` — **مُصلَح** في الإصدارات الحالية.

تأكد من APK محدّث يحتوي:

- `delimiter: '\r'` في `BluetoothService`
- Parser يقسم على `\r\n|\n|\r`

### Binary لا يتفاعل

- تأكد من اختيار **Glove** وليس **Manual**
- ثبّت اليد نصف ثانية (debounce 500ms)
- راجع `FLEX_THRESHOLD` (2000) — قد يحتاج ضبط

## AI Mode

### «Connect glove to start AI mode»

لم يُكتشف اتصال — ارجع للشاشة الرئيسية واتصل.

### «AI model loading…» لا ينتهي / فشل التحميل

```bash
npm run prebuild:android
npm run apk:team
```

تأكد من `withOnnxRuntimePackage.js` ووجود `sign_lstm.onnx` في `assets/models/`.

### «غير معروف» دائماً

- سجّل مدة أطول (1–2 ثانية)
- تأكد أن الحساسات تتغير أثناء التسجيل
- الإيماءة قد لا تكون ضمن الـ 20 فئة المدربة
- ثقة أقل من 0.35 تُعامل كغير معروف

### Stop Recording بدون نتيجة

أقل من **5 إطارات** مُجمَّعة — سجّل مدة أطول أو تحقق من تدفق البيانات.

## STT (المايك)

### «التعرف غير متاح»

- ثبّت **Google** من Play Store
- فعّل الإنترنت للوضع online
- أو حمّل حزمة Arabic offline من إعدادات Google Voice

### أجهزة بدون Google (Huawei بدون GMS)

STT قد لا يعمل — لا حل موحّد بدون خدمة Google.

### المايك لا يلتقط

- صلاحية RECORD_AUDIO
- أغلق التطبيقات الأخرى التي تستخدم المايك

## البناء والتثبيت

| المشكلة | الحل |
|---------|------|
| APK لا يُثبَّت | احذف النسخة القديمة أولاً |
| Crash فور الفتح | ONNX غير مسجّل — أعد prebuild |
| `app-release.apk` busy | أغلق الملف وأعد البناء |
| Crash على المحاكي مع APK team | طبيعي — APK ARM فقط؛ استخدم جهازاً حقيقياً |
| `libreactnative.so not found` | نفس السبب — ARM APK على x86 emulator |

## سجل تشخيصي سريع

```text
□ القفاز يظهر READY على OLED
□ Pair من إعدادات Android (ليس فقط من التطبيق)
□ signTalker: Connected
□ Binary + Glove: البتات تتغير عند تحريك الأصابع
□ AI: Start → حركة → Stop → كلمة أو «غير معروف»
□ STT: مايك + إنترنت أو حزمة offline
```

---

## الحصول على مساعدة

عند الإبلاغ عن مشكلة، أرفق:

1. ماركة الهاتف + إصدار Android
2. هل المشكلة في Binary / AI / STT / الاتصال
3. لقطة شاشة من حالة الاتصال
4. هل flex يتغير عند تحريك الأصابع (Binary Mode)
