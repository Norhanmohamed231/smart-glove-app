# العضو 10 — جمع البيانات والـ Labeling

| الحقل | القيمة |
|-------|--------|
| **العضو** | _[اكتب الاسم]_ |
| **المحور** | الذكاء الاصطناعي (AI) |
| **الدور** | تنفيذ جلسات التسجيل، تنظيف البيانات، ووسم العينات |

---

## المسؤولية باختصار

تنفيذ **بروتوكول العضو 09** عملياً: تسجيل جلسات بالقفاز، حفظ ملفات CSV/جلسات، **تسمية** كل عينة بالفئة الصحيحة، إزالة العينات السيئة، وتسليم مجموعة نظيفة للتدريب.

---

## المخرجات الرئيسية

- [ ] مجلد dataset منظم (مثلاً `data/raw/`, `data/clean/`)
- [ ] عدد عينات محقق لكل فئة (جدول إحصائي)
- [ ] سجل جلسات التسجيل (تاريخ، متطوع، جهاز)
- [ ] تقرير جودة: عينات محذوفة ولماذا
- [ ] تسليم لـ **11** بصيغة جاهزة للتدريب

---

## أدوات محتملة

| الأداة | الاستخدام |
|--------|-----------|
| القفاز + firmware **08** | مصدر البيانات |
| Serial/BT logging | تسجيل خام |
| Python / Pandas | تنظيف وتقسيم |
| Scripts في ريبو AI | تحويل لصيغة تدريب |

---

## الاعتماد على باقي الفريق

| يتنسق مع | لماذا |
|----------|--------|
| **09** | البروتوكول |
| **06–08** | قفاز يعمل بقراءات صحيحة |
| **05** | راحة القفاز في جلسات طويلة |
| **11** | صيغة الملفات المتوقعة |

---

## ما يقدّمه في العرض

1. عدد الجلسات والساعات الإجمالية.
2. هيكل مجلدات الـ dataset (شجرة ملفات).
3. مثال: عينة خام → بعد التنظيف.
4. إحصائيات: عينات/فئة، توازن الفئات.
5. صعوبات الجمع (متطوعون، ضوضاء، أعطال).
