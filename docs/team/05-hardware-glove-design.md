# العضو 05 — تصميم القفاز الميكانيكي

| الحقل | القيمة |
|-------|--------|
| **العضو** | _[اكتب الاسم]_ |
| **المحور** | الهاردوير (Hardware) |
| **الدور** | تصميم فيزيائي للقفاز — هيكل، تثبيت الحساسات، تجربة المستخدم |

---

## المسؤولية باختصار

كل ما يخص **الشكل الفيزيائي** للقفاز: اختيار القفاز/القاعدة، مواقع تركيب **5 flex + MPU + OLED + ESP32**، التوصيلات، الراحة، والمتانة. ليس مسؤولاً عن كود الـ firmware (08) لكن يتنسق مع 06 و 07 لمواقع الحساسات.

---

## المخرجات الرئيسية

- [ ] نموذج أولي (prototype) يرتديه المستخدم
- [ ] مخطط مواقع الحساسات على الأصابع (Thumb → Pinky)
- [ ] تثبيت آمن للوحة ESP32 وشاشة OLED
- [ ] توثيق صور/رسوم للتصميم النهائي
- [ ] قائمة مواد (BOM) إن وُجدت

---

## المجالات التقنية

| الموضوع | التفاصيل |
|---------|----------|
| اختيار القفاز | قماش/شبك يسمح بثني الأصابع |
| تثبيت Flex | لا يمنع الحركة الطبيعية |
| توزيع الأسلاك | تقليل الشد على المفاصل |
| الوزن والتوازن | البطارية/اللوحة لا تعيق الحركة |
| Ergonomics | راحة جلسات التسجيل الطويلة (AI dataset) |

---

## الاعتماد على باقي الفريق

| يتنسق مع | لماذا |
|----------|--------|
| **06** | مواقع دبابيس Flex (35, 32, 33, 25, 26) |
| **07** | موقع MPU6050 ثابت نسبياً على الظهر |
| **08** | مساحة OLED 128×32 على I2C |
| **09–10** | راحة القفاز أثناء جمع الداتا |

---

## ما يقدّمه في العرض

1. متطلبات التصميم (5 أصابع + IMU + عرض).
2. صور النموذج الأولي والنهائي.
3. تحديات ميكانيكية (أسلاك، ثبات الحساسات).
4. كيف يخدم التصميم دقة Binary و AI.
5. اقتراحات تحسين مستقبلية.
