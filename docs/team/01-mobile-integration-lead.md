## المسؤولية باختصار

ربط كل أجزاء التطبيق في مسار واحد يعمل من الاتصال بالقفاز حتى العرض والنطق والسجل. الإشراف على الوثائق، بناء APK للفريق، وتنسيق التكامل مع فريقي الهاردوير والـ AI.

---

## المخرجات الرئيسية (Deliverables)

- [ ] تطبيق يعمل end-to-end على Android (اتصال → Binary/AI → TTS → History)
- [ ] وثائق المشروع في `docs/` محدّثة ومتسقة
- [ ] APK release للفريق (`npm run apk:team`)
- [ ] خطة اختبار تكامل موثّقة
- [ ] عرض تقديمي: **نظرة عامة على النظام الكامل**

## ما يقدّمه في العرض (5–7 دقائق)

1. **المشكلة:** حاجة لوسيط بين قفاز الإشارة والمحيط.
2. **الحل:** signTalker — 3 محاور (هاردوير، AI، تطبيق).
3. **مخطط التدفق:** ESP32 → BT → Parser → Binary/AI → UI + TTS.
4. **دورك:** التكامل، الـ store، الـ provider، الوثائق، APK.
5. **Demo:** مسار كامل مختصر (اتصال → وضع → نتيجة).
6. **التحديات:** ONNX native، delimiter `\r`، صلاحيات Android.
