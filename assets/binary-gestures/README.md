# Binary Gesture Illustrations — Catalog

32 hand-pattern illustrations for Binary Mode dictionary UI.

**Finger order:** Thumb · Index · Middle · Ring · Pinky  
**bit `0`** = extended · **bit `1`** = bent  
**Regenerate:** `python scripts/generate_binary_gesture_illustrations.py`

Illustrations use premium natural-style SVG: 3-segment extended fingers, 2-segment bent fingers, capsule joints, skin lighting, nail highlights, wrist block, ambient glow, and purple glow on bent digits.
